# 개별 종목 화면 기능 요구사항 정의서

2026.07.09

## 화면 개요

주식 종목의 실시간 차트와 캐릭터 인터랙션을 통합한 핵심 화면으로, 캐릭터가 차트 및 UI 요소와 물리적으로 상호작용한다.

## 기능 목록

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 종목 리스트 | 종목 목록 표시 | 전체 지원 종목을 리스트로 표시하고 선택 시 해당 종목 차트로 전환 | |
| 1-2 | 종목 리스트 | 관심 종목 | 사용자가 관심 등록한 종목을 별도 필터링하여 보여줌 | |
| 2-1 | 실시간 차트 | 실시간 주가 차트 | 선택된 종목의 실시간 캔들/라인 차트 표시 | Chart API |
| 2-2 | 실시간 차트 | 확대/축소 | 차트 기간을 확대/축소하여 보이는 범위 조정 | 스크롤/핀치줌 |
| 2-3 | 실시간 차트 | 차트 타입 자동 전환 | 차트 기간에 따라 캔들/라인 등 차트 타입 자동 변경 | |
| 3-1 | 거래 | 호가창 | 매수/매도 호가 목록 표시 및 호가 클릭 주문 | 매수/매도 버튼 |
| 3-2 | 거래 | 주문 유형 선택 | 시장가/지정가/예약 주문 등 주문 방식 선택 | |
| 3-3 | 거래 | 좌클릭 옵션 | 차트/호가창에서 좌클릭 시 컨텍스트 메뉴 표시 | 알림받기, 예약 |
| 4-1 | 분석 도구 | 보조지표 | 이동평균선, RSI, MACD, 볼린저밴드 등 보조지표 표시 | 캐릭터가 직접 그려줌 |
| 4-2 | 분석 도구 | 그림 그리기 | 차트 위에 추세선, 수평선 등 사용자 직접 그리기 | 캐릭터가 직접 그려 줌 |
| 5-1 | 종목 비교 | 차트 비교 | 한 화면에 2개 종목 차트를 겹쳐 표시하고 캐릭터 2명 동시 등장 | 캐릭터 관계 연출 |
| 6-1 | 종목 정보 | 주식 및 기업 정보  | 시가총액, 배당금, 재무제표 등을 시각화 | 캐릭터 능력치 컨셉 |
| 7-1 | 캐릭터 × 차트 | 차트 연동 크기 변화 | 차트 확대 비율에 비례하여 캐릭터 크기가 커짐 | 확대 → 캐릭터 확대 |
| 7-2 | 캐릭터 × 차트 | 의상 해금 | 일정 등락율 달성 시 의상 해금 | 자동 변화/ 고정 의상 사용자 선택으로 |
| 8-1 | 캐릭터 × UI | 매도 설득 | 매도 버튼 클릭 시 캐릭터가 설득/만류하는 행동 표출 | |
| 9-1 | 캐릭터 뱃지 | 뱃지 | 캐릭터가 기록할만한 경험을 했을 때 뱃지를 획득 (대폭락을 견딤, n주년 보유) | (보류) |

# 커뮤니티 정의서 — 개별 종목 페이지 종속

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 게시글 | 좋아요 | 좋아요 버튼 | |
| 1-2 | 게시글 | 댓글 | 게시글에 댓글 작성 | |
| 2-1 | 사용자 | 닉네임 우클릭 → 포트폴리오 | 사용자 닉네임 우클릭 시 해당 사용자의 포트폴리오 화면 표시 | |
| 2-2 | 사용자 | 대표 캐릭터 표시 | 닉네임 옆에 사용자가 설정한 대표 캐릭터 아이콘 표시 | 전체커뮤 |
| 2-3 | 사용자 | 팔로잉 | 원하는 사용자를 팔로잉한다 | |
| 3-1 | 인기글 | 같은 캐릭터 사용자 유입 알림 | 특정 시간대에 같은 대표 캐릭터 사용자들이 몰리면 알림창 표시 | 전체커뮤 |
| 4-1 | 탐색 | 검색 | 게시글/사용자 키워드 검색 기능 | 전체커뮤 |
| 5-1 | 실시간 핫한 단어 | 실시간 핫한 단어 | 언급량이 많은 정보(거래량, 커뮤니티 언급량 등) 순위 | 전체커뮤 |
| 6-1 | 투표 | 매수/매도 투표 | 종목별 '사야 할까? 팔아야 할까?' 투표 개설 및 결과 표시 | |
