# 거실 탐색 페이지 기능 요구사항 정의서

2026.07.09

## 화면 개요

여러 사용자의 거실(포트폴리오)을 썸네일 그리드로 나열하고 검색·정렬·순위별로 둘러보는 탐색 화면. (UI 참고: 오늘의집/다방식 카드 그리드)

## 기능 목록

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 레이아웃 | 거실 썸네일 그리드 | 사용자 거실 썸네일 카드를 그리드로 나열 | 오늘의집 스타일 |
| 1-2 | 레이아웃 | 거실 카드 정보 | 거실 썸네일 + 닉네임 + 성향 태그 + 수익률 지표 표시 | |
| 2-1 | 큐레이션 | 오늘의 폭등한 거실 | 당일 수익률이 크게 상승한 사용자의 거실을 모아 노출 | 동의한 사용자만 |
| 2-2 | 큐레이션 | 오늘의 폭락한 거실 | 당일 수익률이 크게 하락한 사용자의 거실을 모아 노출 | 동의한 사용자만 |
| 2-3 | 큐레이션 | 공유 선택 | 사용자가 동의한 경우에만 큐레이션 섹션에 노출 | 원치 않는 노출 방지 |
| 3-1 | 태그 | 성향 태그(자기신고) | 사용자가 본인 투자 성향 태그를 직접 선택 (장기투자/단기투자/안정추구 등) | 거실 설정에서 지정 |
| 3-2 | 태그 | 시스템 태그(자동) | 평균 보유 기간, 수익률 변동량 등 단순 지표 기반으로 자동 부여 | 복잡한 알고리즘 없이 2~3종 |
| 4-1 | 검색/정렬 | 태그 필터 | 성향 태그/시스템 태그 기준으로 거실 필터링 | 사용자 시점에서는 3-1과 3-2가 구분 안됨 |
| 4-2 | 검색/정렬 | 종목 검색 | 특정 종목을 보유한 사용자의 거실 검색 | |
| 4-3 | 검색/정렬 | 순위 보기 | 정렬 기준별 상위 거실을 순위 형태로 표시 | 큐레이션 섹션은 일간 수익률 변동폭 기준 |
| 4-4 | 검색/정렬 | 유사도 정렬 | 내 거실 태그와 종목을 자동 적용해서 나와 유사한 거실 찾기 | 나와 정반대의 거실 찾기도 가능 |
| 5-1 | 거실 방문 | 타 거실 열람 | 카드 클릭 시 해당 사용자의 거실(포트폴리오 화면) 진입 | |
| 5-2 | 거실 방문 | 이모티콘 반응 | 방문한 거실/캐릭터/오브젝트에 간단한 이모티콘(따봉/슬퍼요 등)을 남김 | |
| 6-1 | 방명록 | 방명록 작성 | 방문자가 거실에 공개 글을 남김 | |
| 6-2 | 방명록 | 비밀글 | 거실 주인만 열람 가능한 글 작성 | 개인적인 조언 요청 용도 |
| 6-3 | 방명록 | 답글 | 거실 주인이 방명록 글에 답글 작성 | |
