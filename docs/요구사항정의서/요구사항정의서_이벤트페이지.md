# 이벤트 페이지 기능 요구사항 정의서

2026.07.09

## 화면 개요

주식에 사건(예고형: 실적 발표 / 돌발형: 폭락·급등)이 발생했을 때만 열리는 한시적 광장.

## 기능 목록

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 개방 조건 | 예고형 이벤트 | - | 연출적인 부분이므로 개별종목화면으로 이동 (보류) |
| 1-2 | 개방 조건 | 돌발형 이벤트 | 폭락/급등 등 시장 지표가 조건을 충족하면 자동 개방 | 임계값 기준, 매커니즘 구체화 필요 |
| 2-1 | 폐쇄 조건 | 이벤트 종료 | 장 마감/전환 시 종료 | 해외 주식 리서치 필요 |
| 3-1 | 접근 | 개방 알림 | 이벤트 발생 시 사용자에게 알림| 연출 : 돌발형은 사이렌|
| 4-1 | 광장 화면 | 광장 입장 | 랜덤한 사용자 n명이 한 광장에 모임 |  n = 동시성 감당 가능한 제한 인원수, 비접속 사용자 포함 |
| 4-2 | 광장 화면 | 전광판 | 광장의 전광판에 사건 정보를 크게 표시 | 차트와 실시간 거래량 |
| 4-3 | 광장 화면 | 광장 톤 변화 | 사건에 따라 광장의 분위기/디자인 변화 | 예: 폭락=폭풍우, 급등=축제 |
| 5-1 | 캐릭터 | 사용자 커스텀 반영 | 각 사용자가 꾸민 캐릭터 모습 그대로 광장에 나타남 | |
| 5-2 | 캐릭터 | 보유 뱃지 표시 | 사용자가 설정한 대표 뱃지 2~3개를 표시함 | |
| 5-3 | 캐릭터 | 판매자 퇴장 | 못 버티고 손절(전량 매도)한 사용자의 캐릭터는 하늘로 승천 | |
| 5-4 | 캐릭터 | 구입자 입장 | 이벤트 중 새로 유입된 사용자의 캐릭터에 NEW 표시 | |
| 6-1 | 아이템 | 뱃지 지급 | 이벤트 참여 결과에 따른 뱃지 지급 | 소장품 아이템 |
