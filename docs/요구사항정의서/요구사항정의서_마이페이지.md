# 마이페이지 기능 요구사항 정의서

2026.07.09

## 화면 개요

사용자의 상세 정보(보유 자산, 거래 내역, 계정 설정 등)를 조회·관리하는 화면.

## 기능 목록

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 페이지 구조 | 사이드바 탭 | 좌측 사이드바에 자산 / 거래 내역 / 작성 글·댓글 조회 3개 탭 | |
| 2-1 | 내 정보 탭 | 자산 정보 표시 | 총주문가능금액, 총투자금액, 판매수익, 배당금(수익), 이자(수익) 표시 | 메인 영역 상단 |
| 2-2 | 내 정보 탭 | 보유 주식 카드형 뷰 | 보유 종목별 캐릭터 카드를 썸네일 그리드로 표시 | 전체커뮤|
| 2-3 | 내 정보 탭 | 보유 주식 텍스트 리스트형 뷰 | 종목 단위 행 리스트로 현재가, 보유 주 수, 수익률, 평가손익 표시 | |
| 2-4 | 내 정보 탭 | 뷰모드 토글 | 대표 캐릭터 설정 영역의 토글 버튼으로 카드형/리스트형 전환 | 전체커뮤 |
| 2-5 | 내 정보 탭 | 대표 캐릭터 설정 | 카드형 뷰에서 캐릭터 카드 클릭 시 대표 캐릭터로 설정 | 전체커뮤  |
| 2-6 | 내 정보 탭 | 닉네임 설정 | '닉네임 설정' 버튼 → 모달에서 입력 + 중복 확인 → 변경 적용 | 가입 시 기본 닉네임 자동 생성 |
| 2-7 | 내 정보 탭 | 팔로워/팔로잉 | 나의 팔로워/팔로잉을 조회 및 관리 | |
| 3-1 | 거래 내역 탭 | 필터 | 유형(전체/매도/매수) + 기간(시작일~종료일) 필터, 조회 버튼 | |
| 3-2 | 거래 내역 탭 | 거래 내역 리스트 | 종목명+거래 일자, 유형, 수량(주), 단가, 손익, 수익률 행 표시 | 행 클릭 동작 없음 |
| 4-1 | 작성 글/댓글 탭 | 작성 글/댓글 목록 | 상단에 작성 글 목록, 하단에 작성 댓글 목록 표시 | 방명록/커뮤 구분 |
| 4-2 | 작성 글/댓글 탭 | 게시글 이동 | 항목 클릭 시 커뮤니티 해당 게시글/방명록으로 이동 | |
| 5-1 | 접근 제어 | 비로그인 리다이렉트 | 비로그인 접근 시 로그인 페이지로 리다이렉트 | |
