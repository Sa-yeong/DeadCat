# 전체 종목 리스트 기능 요구사항 정의서

2026.07.09

## 화면 개요

전체 지원 종목과 섹터별 분류를 순위 리스트로 보여주는 풀페이지 화면. 상단 지수 슬라이드 + 좌측 리스트 + 우측 캐릭터 썸네일 영역으로 구성. (모바일 미지원)

## 기능 목록

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 페이지 구조 | 탭 구성 | '전체 종목' 탭 / '카테고리 별 분류' 탭 | |
| 1-2 | 페이지 구조 | 캐릭터 썸네일 영역 | 우측에 선택된 종목/카테고리의 캐릭터 썸네일 표시 | |
| 2-1 | 지수 영역 | 지수 케러셀 | 상단에 지수명·등락률·지수 캐릭터 이미지 표시, 좌우 화살표로 이전/다음 지수 전환 | NASDAQ/KOSPI/DJX 등. 지수 캐릭터는 이미지 자산만(3D 없음) |
| 3-1 | 전체 종목 탭 | 종목 리스트 | 하트, 순위, 종목 로고, 종목 이름, 현재가, 등락률, 거래대금(억) 행 표시. | 현재 구현상 거래대금순 고정 (중요도 낮음) |
| 3-2 | 전체 종목 탭 | 관심 종목 등록 | 하트 클릭 시 관심 종목 등록/해제 토글 | 비로그인 시 작은 로그인 모달 표시 |
| 3-3 | 전체 종목 탭 | 종목 행 마우스 오버 | 우측 캐릭터 썸네일 갱신 | |
| 3-4 | 전체 종목 탭 | 종목 행 클릭 | 개별 종목 화면으로 이동 | |
| 4-1 | 카테고리 탭 | 섹터 리스트 | 순위, 섹터 아이콘, 섹터 이름, 상승률 행 표시 | 분류 기준=주식 섹터. 하트 미표시 |
| 4-2 | 카테고리 탭 | 카테고리 행 마우스 오버 | 우측에 해당 섹터 캐릭터들의 군집 이미지 표시 | |
| 4-3 | 카테고리 탭 | 카테고리 행 클릭 | 해당 분류에 포함된 캐릭터/종목 나열 모달 표시 | |
