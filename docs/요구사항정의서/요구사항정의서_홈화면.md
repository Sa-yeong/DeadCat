# 홈화면 기능 요구사항 정의서

2026.07.09

## 화면 개요

접속 시 처음 만나는 메인 화면. 보유 주식 캐릭터들이 함께 생활하는 거실(개인 포트폴리오) 공간으로, 포트폴리오 현황 확인과 캐릭터 상호작용이 이루어진다.

## 기능 목록

| No | 분류 | 기능명 | 설명 | 비고 |
|---|---|---|---|---|
| 1-1 | 배경 | 자산/수익률 표시 | 보유 자산 총액과 총 수익률 표시 | |
| 1-2 | 배경 | 창문 차트 배경 | 배경 창문에 대표 주식 차트 1개를 활용한 배경 이미지 생성 | 날씨 정보를 이용해 배경 변경 (보류) |
| 2-1 | 출석체크 | 출석체크 보상 | 출석 시 소정의 보상 아이템 지급 | |
| 3-1 | 캐릭터 상호작용 | 아이템 증여 | 보상 아이템을 원하는 캐릭터에게 건네면 호감도 상승 | |
| 3-2 | 캐릭터 상호작용 | 호감도 시스템 | 호감도 레벨에 따라 캐릭터의 행동/대사가 변화 | 아이템 증여 + 보유기간 + 보유 주식 수로  상승, 반대는 하락|
| 3-3 | 캐릭터 상호작용 | 호감도 MAX 보상 | 호감도 최대 달성 시 캐릭터 고유 아이템 선물 | 캐릭터별 고유 |
| 4-1 | 캐릭터 행동 | 3D 오브젝트 상호작용 | 캐릭터가 3D 오브젝트와 상호작용 | |
| 4-2 | 캐릭터 행동 | 캐릭터 상태 가공 | 실시간 주가 + 캐릭터 태그(성격/설정)를 조합하여 캐릭터의 감정/무드 산출 | |
| 4-3 | 캐릭터 행동 | 캐릭터 상태 가공 | 사용자가 보유하고 있는 주수를 바탕으로 캐릭터가 변화 | |
| 4-4 | 캐릭터 행동 | 관계도 생성 | 사용자 개인 데이터 기반으로 캐릭터 간 관계도를 생성 및 갱신 | |
| 5-1 | 거래 내역 | 이별 흔적 | 매도하여 떠난 캐릭터의 흔적을 이별선물/카드 형태로 보관 | 부분 매도가 아닌 전체 매도 시 |
| 6-1 | 꾸미기 | 가구+캐릭터 배치 | 보유한 가구와 캐릭터를 거실에 배치할 수 있음 | 배치 모드로 변경 (뷰모드 변경, 페이지 이동x), 토글 버튼  |
| 6-2 | 꾸미기 | 옷 입히기 | 보유한 의상으로 캐릭터 의상을 변경할 수 있음 | 갤러리 모드로 변경 (뷰모드 변경, 페이지 이동x), 캐릭터 개별 클릭 |
